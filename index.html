Welcome to ZCare Support.

ZCare is designed to make everyday tasks simpler and more accessible. This page provides help and information for ZCare users.

About ZCare

ZCare helps users manage appointments and notes, save important phone numbers, access favourite apps and links, and use accessibility features designed for easier navigation.

Appointments

ZCare allows you to create and manage appointments and notes. You can enter information using text or supported voice features and review appointment details before saving them.

Phone Numbers

Save important phone numbers inside ZCare for convenient access.

Favourite Apps

ZCare lets you save favourite links so you can quickly open supported apps or websites.

Accessibility

ZCare includes accessibility options such as adjustable text size, high contrast, voice assistance, and simple navigation.

Languages

ZCare supports English and Arabic.

Need Help?

If you experience a problem with ZCare or need assistance, please contact the ZCare support team.
